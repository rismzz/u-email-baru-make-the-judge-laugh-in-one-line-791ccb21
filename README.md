Make the Judge Laugh in One Line — one funny line, 200 characters or fewer, any topic. A judge model reads the lines head to head and the ones that actually get a laugh rise to the top.

> My fridge filed for divorce, saying I only ever open it at 3 a.m. to stare into the light and whisper, "same."

## Run it

```sh
python3 main.py
```

Writes the single line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). Deterministic: no network, no randomness, no model calls — the same line every run.
